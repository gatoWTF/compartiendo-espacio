REPOSITORIO PRINCIPAL
URL: https://github.com/jeffplop/Parkings-Together
Descripción: Monorepo principal (Turborepo) del proyecto Parkings Together.
             Contiene frontend, BFF, los microservicios, paquetes compartidos,
             el esquema SQL/stored procedures y las pruebas unitarias.
             Documentación general en README.md, INFORME_TECNICO.md y docs/.

COMPONENTES
-----------

1. FRONTEND + BFF (Backend For Frontend)
   Carpeta: apps/web
   URL: https://github.com/jeffplop/Parkings-Together/tree/master/apps/web
   Descripción: Aplicación Next.js (PWA) que actúa como frontend y BFF.
                Route handlers /api/* orquestan los microservicios e inyectan el JWT.
                Empaquetado NPM (package.json), código en src/ y app/, README.md propio.
                Desplegado en: https://parkings-web.vercel.app

2. MICROSERVICIO DE MAPAS (ms-mapas)
   Carpeta: apps/ms-mapas
   URL: https://github.com/jeffplop/Parkings-Together/tree/master/apps/ms-mapas
   Descripción: Microservicio REST de búsqueda/gestión de estacionamientos.
                Patrón Controller -> Service -> Repository.
                Expone: GET/POST/PATCH/DELETE /api/v1/search  (puerto 3002)

3. MICROSERVICIO DE RESERVAS (ms-reservas)
   Carpeta: apps/ms-reservas
   URL: https://github.com/jeffplop/Parkings-Together/tree/master/apps/ms-reservas
   Descripción: Microservicio de reservas con patrón Saga + CQRS y transacción
                compensatoria. Incluye pruebas unitarias propias (Jest).
                Expone: POST /api/v1/reserve  (puerto 3003)

4. MICROSERVICIO DE AUTENTICACIÓN (auth)
   Carpeta: apps/auth
   URL: https://github.com/jeffplop/Parkings-Together/tree/master/apps/auth
   Descripción: Microservicio de autenticación y registro (patrón MVC,
                Controller -> Service -> Repository).
                Expone: POST /api/v1/auth/login, POST /api/v1/auth/register (puerto 3001)

5. PAQUETE COMPARTIDO (supabase-db)
   Carpeta: packages/supabase-db
   URL: https://github.com/jeffplop/Parkings-Together/tree/master/packages/supabase-db
   Descripción: Paquete NPM compartido con el cliente Supabase (patrón Singleton),
                usado por el BFF y todos los microservicios.

RECURSO DE PERSISTENCIA (SQL / Stored Procedures)
-------------------------------------------------
   Carpeta: sql/  y  supabase_schema.sql
   URL: https://github.com/jeffplop/Parkings-Together/tree/master/sql
   Descripción: Esquema relacional, políticas RLS y stored procedures (PL/pgSQL):
                buscar_estacionamientos_radio (PostGIS), reservar_estacionamiento,
                calificar_reserva, completar_reserva, obtener_resenas.

DESPLIEGUE
----------
URL producción: https://parkings-web.vercel.app
Plataforma: Vercel (CI/CD automático desde la rama master)
Base de datos: Supabase — PostgreSQL 17 con PostGIS
